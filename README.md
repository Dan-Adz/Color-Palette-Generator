# Color-Palette-Generator
Color Palette Generator made with Python version 3.12 and HTMl

Before running the server, the index.html file needs to be moved into a folder called templates in the same repository as the server.

Once you run the server file you can open the color palette generator from the link and select an image from the same repository as the server file to generate a color palette for in either hexadecimal or RGB.

The colors will then be displayed in the form you selected.
